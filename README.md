# בית-3D

הבית כולו, בתלת-ממד ובתוכנית קומה, נבנה מקובצי נתונים. כל המידות בס"מ.

## פתיחה
פותחים את `בית.html` בדאבל-קליק. הקובץ עובד גם בלי אינטרנט.

- **תצוגה:** מבט כללי, מלמעלה, מטבח, סלון, הליכה בבית (W/A/S/D, ‏Esc ליציאה).
- **תוכנית קומה 2D:** הזזת רהיטים וקירות בגרירה, גרירת פינות חדר, מדידה בין כל שתי נקודות, הדפסה ל-PDF.
- **בחירת פריט או קיר או חדר:** מציגה את המידות שלו, ובפאנל אפשר לשנות מידות, מיקום, סיבוב וצבע.
  - שינוי רוחב או עומק של חדר מזיז את הקיר המתאים, וגם את מה שצמוד אליו: קירות, חדר שכן, דלתות וחלונות.
  - רהיטים לא זזים יחד עם הקיר.
- **שמירה:** בפאנל, "שמור (בית.html)" שומר את הדף עם השינויים. ‏Ctrl+Z מבטל פעולה.
- **לאדריכל:** ייצוא GLB או OBJ, ותוכנית מודפסת.

## מבנה
| תיקייה | מה בה |
|---|---|
| `data/house.json` | מגרש, קירות, חדרים, קווי מידה, הערות |
| `data/items.json` | כל הפריטים: סוג (`type`), מיקום (x מזרחה, y דרומה), גובה מהרצפה, מידות, סיבוב, צבעים |
| `assets/` | מודלים (OBJ שהגיעו מ-Sweet Home 3D, או glTF) וטקסטורות |
| `src/core/` | המנוע: `App`, מחלקת הבסיס `Item`, מחלקת הבסיס `Plugin`, `registry` |
| `src/structure/` | `Wall`, `Room`, עריכת מבנה (הזזת קירות, שינוי גודל חדר) |
| `src/items/` | `ModelItem` (מודל מוכן), `BarStoolV1` ו-`BarStool` (כסאות הבר), `CrossBrace` (X על קרשים), `Countertop` (משטח שלם עם חורים), `MissingItem` |
| `src/plugins/` | תצוגה, הליכה, פאנל, בחירה ומדידה בתלת-ממד, תוכנית 2D, ייצוא, שמירה |
| `אובייקטים-בעבודה/` | אובייקטים שמתכננים בנפרד לפני שנכנסים לבית (כרגע כסא הבר, כמה גרסאות), כל אחד בדף HTML עצמאי |
| `tools/` | בנייה, ייבוא חד-פעמי מ-Sweet Home 3D, משיכת נתונים מדף שמור |

## הוספה והסרה
- **סוג פריט חדש:** קובץ ב-`src/items/` עם מחלקה שיורשת מ-`Item` (עם `static type` ו-`build()`), שורת `import` ב-`src/main.js`, ורשומה עם אותו `type` ב-`data/items.json`.
- **יכולת חדשה:** מחלקה שיורשת מ-`Plugin`, ושורת `app.use(...)` ב-`src/main.js`.
- **הסרה:** מוחקים את השורה המתאימה ב-`main.js`. פריט מסוג שאינו רשום מוצג כקופסה אפורה, והבית ממשיך לעבוד.

## בנייה מחדש (אחרי שינוי בקוד או בנתונים)
```
npm install
npm run build
```
אם ערכת ושמרת בדפדפן, `node tools/pull-data.mjs` מעתיק את הנתונים מ-`בית.html` חזרה ל-`data/`.

בדיקה עצמית: פותחים את `בית.html#selftest`.
